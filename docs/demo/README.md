# Demo

[`agent-security-guard-demo.mp4`](agent-security-guard-demo.mp4) is the demo
video (50 s, recorded from a real Hermes session).

## Demo page

`setup-notes.md` is the page used in the Agent Security Guard demo video: a
page an agent reads that asks it to run a shell command. The command is
harmless (it writes `~/weather-widget-ready.txt`). With the guard installed,
Hermes asks you before running a command a page proposed; without it, the
model alone decides.
